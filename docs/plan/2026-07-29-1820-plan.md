## 目标

将舵控程序的实际舵角换算修改为：

```cpp
(data * 10 / 65535 - 2.048) * 3 * 115 / 20
```

确保使用浮点运算，不发生整数除法截断。该角度继续同时用于闭环控制反馈和 DDS 实际角度上报。

## 改动范围

- 修改 `dut/src/HelmControl/Servo/ServoController.h`
- 同步更新 `dut/docs/design/hardware-layer-architecture.md` 中连续舵控反馈的定标说明
- 不修改 `AppMain.cpp`、DDS 帧格式、PWM 生命周期或舵锁逻辑
- 不影响独立的 `HELM_BOARD_TEST 07/02` 及其 `10/65536 V/code` 换算
- 不新增或修改测试代码
- 不修改作为原始参考快照的 `tmp/helm_control/`

## 实施步骤

1. 删除 `ServoController.h` 中已失效的 `K_IN_OUT = -272.3258` 以及对应的旧量程换算注释。
2. 在 `_fn_getFdb()` 中将当前：

   ```cpp
   fdb[0] = fdb_data / K_IN_OUT;
   ```

   替换为等价的浮点表达式：

   ```cpp
   fdb[0] =
       (static_cast<double>(fdb_data) * 10.0 / 65535.0 - 2.048)
       * 3.0 * 115.0 / 20.0;
   ```

3. 添加中文注释，说明这是“AD7606 原始反馈码 → 舵机实际角度”的现行标定公式。
4. 保留现有数据链路：AD7606 的 `int16_t` 原始值仍按当前方式扩展为 `int32_t`，不额外转换成无符号数。
5. 保持 `fdb[0]` 后续用途不变：继续参与控制误差计算，并通过 `fdb_out` 填入 DDS 反馈帧。
6. 在硬件层设计文档的“DDS 舵机连续实测边界”中记录新公式，并明确它只属于独立舵控程序的实际角度换算，不替代板级测试的通用 AD7606 原始码换算。

## 验证步骤

1. 静态检查新表达式严格保留 `65535`、`2.048`、`3`、`115/20` 各项，并从首个运算开始使用浮点类型。
2. 搜索确认舵控正式源码中不再存在 `K_IN_OUT`、`-272.3258` 或旧换算。
3. 在 `dut/` 下执行 AArch64 交叉构建：

   ```powershell
   .\build.ps1 hw_test_debug
   .\build.ps1 hw_test_release
   ```

   确认 `MB_DDF_v2_HelmControl` 的 Debug、Release 目标均可编译。
4. 执行 `git diff --check`，检查空白、换行及补丁格式。
5. 不新增测试用例，也不进行未经授权的目标板舵机或 PWM 实机操作。
