# CPU spidev N25Q512A Flash Demo Implementation Plan

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development while implementing this plan task-by-task.

**Goal:** 新增基于 CPU `/dev/spidev0.0` 的 Micron N25Q512A SPI Flash 驱动与可恢复读写测试，并在完整硬件 Demo 中替代原 FPGA Flash 整片擦除测试。

**Architecture:** 新增独立于寄存器/XDMA `ITransport` 的 SPI 全双工传输接口，Linux 实现用单次 `SPI_IOC_MESSAGE(1)` 保持片选；协议设备层使用 N25Q512A 专用四字节命令 `13h/12h/21h`，不改变全局地址模式。Demo 只测试一个 4 KiB 子扇区，先完整备份，擦除/写入/读回验证后再擦除并逐页恢复，最后全块校验。

**Tech Stack:** C++20、Linux spidev ioctl、GoogleTest、CMake、AArch64 交叉编译、PowerShell 部署脚本。
