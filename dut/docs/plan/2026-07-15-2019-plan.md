# 日志区域横向布局调整方案

## 目标

将 PC 串口工具的日志区域从主内容下方移动到右侧。

硬件测试模式形成：

```text
测试项与参数 | 响应字段 | 日志
```

回显模式仍保留右侧日志，不改变串口、协议或日志处理逻辑。

## 改动范围

仅修改：

- `test_pyqt/main_window.py`

不修改：

- 串口收发与协议代码
- 硬件测试会话逻辑
- 测试文件
- 文档
- 窗口现有最小尺寸和默认尺寸

## 实施步骤

1. 在 `_build_ui()` 中新增外层水平 `QSplitter`，放置于工作模式和串口连接区域下方。

2. 将现有 `self.mode_stack` 放到外层 Splitter 左侧。硬件测试页内部原有的“测试项/参数”和“响应字段”Splitter 保持不变。

3. 新建日志容器 `log_panel`：

   - 使用垂直布局。
   - 顶部保留“日志”标题、弹性空白和“清空”按钮。
   - 下方放置现有 `self.log_edit`。
   - 不重建 `ColoredLog`，保持日志颜色、最大行数和信号连接不变。

4. 将日志容器放到外层 Splitter 右侧，设置：

   - 左右伸缩比例约为 `2:1`。
   - 初始尺寸约为 `[720, 360]`。
   - 禁止任一侧被完全折叠。
   - 允许用户拖动分隔条调整响应区和日志区宽度。

5. 根布局只保留：

```python
root.addWidget(mode_group)
root.addWidget(connection_group)
root.addWidget(content_splitter, 1)
```

删除原来把日志放到底部的三个布局入口：

```python
root.addWidget(self.mode_stack, 1)
root.addLayout(log_header)
root.addWidget(self.log_edit, 1)
```

6. 保持以下行为不变：

   - “清空”按钮仍连接 `self.log_edit.clear`。
   - 所有 TX、RX、协议错误和硬件测试日志继续写入同一个 `log_edit`。
   - 切换回显/硬件测试模式时日志内容不清空、不隐藏。
   - 响应字段表格的列宽和刷新逻辑不变。

## 验证步骤

按用户要求不运行 pytest、GUI、串口或目标板测试，仅进行静态检查：

1. 使用 `git diff --check` 检查格式问题。
2. 确认根布局中不再存在底部日志布局语句。
3. 确认外层 Splitter 的顺序为 `mode_stack` 在左、日志容器在右。
4. 确认 `clear_log_button`、`log_edit`、`ColoredLog` 和既有信号连接没有被删除或重复创建。
5. 确认改动仅涉及 `test_pyqt/main_window.py`。
