# PC 硬件测试多标签页改造方案

## 目标

将当前“测试树 + 动态参数区 + 通用响应表”重构为协议专用界面：

- 使用左侧纵向标签导航，包含“连接与日志”“串口回显”和 12 个硬件测试页。
- 每个测试页独立保存参数、状态和最近一次结果。
- 根据协议字段选择位图、开关、指标、表格或图表，不再把所有结果都显示成通用字段表。
- 保持串口、产品协议、执行顺序和板端行为不变，不增加测量阈值或“测试通过”推断。

采用单层纵向标签，而不使用横向 14 标签或“模式切换 + 二级标签”，避免标签溢出和重复导航。

## 改动范围

新增：

- `test_pyqt/ui_theme.py`：Win7 兼容的统一 QSS、颜色和尺寸常量。
- `test_pyqt/test_page_widgets.py`：状态栏、指标区、位图网格、原始字段表等复用控件。
- `test_pyqt/hardware_test_pages.py`：12 个协议专用页面及页面工厂。
- `test_pyqt/tests/test_hardware_test_pages.py`：页面参数和响应映射测试。

修改：

- `test_pyqt/main.py`：应用全局主题。
- `test_pyqt/main_window.py`：窗口壳、标签导航、模式切换和响应路由。
- `test_pyqt/tests/test_main_window.py`：替换测试树相关断言，覆盖新导航。
- `docs/guides/demo-usage.md`：更新操作入口。
- `docs/tests/README.md`：更新界面测试范围。

不修改：

- 产品协议 CSV、物理串口协议、AArch64 C++ 和硬件寄存器。
- `HardwareTestSession` 的请求时序、执行全部顺序、DH/舵控/定时器复合流程。
- 当前 mode 0/1 和“STOP ACK 不覆盖定时器统计”的回归行为。

## 页面设计

| 标签页 | 输入控件 | 主要结果 |
|---|---|---|
| 系统状态 | 无参数，“读取状态” | CPU/内存占用、大小核 MHz、PCIe GT/s 与宽度、初始化时间、温度、通电时间 |
| 内存 | 类型下拉、长度步进器、U32 种子 | 错误数、首错地址、耗时、读写 MB/s |
| SPI Flash | 无参数，固定测试区风险提示 | 执行状态、耗时 |
| 总线 | LOOP/ECHO 分段选择、带名称的 link 下拉、次数或十六进制数据 | LOOP 统计或收发数据对照 |
| DI | 无参数 | 两组 U32 的只读位状态网格 |
| DO | 16 个通道复选框、全清/全选 | 已生效输出位图；固定生成 `channel[1]=0` |
| 电源 | DYT、24V_SY、5V_JS 三个复选框 | 三路命令回读；失败响应不把默认零显示为有效值 |
| 电气健康 | 无参数 | B/C 电压与门限、电源轨、8 位激活状态 |
| AD | 无参数 | 引信遥测和 FK1-FK4 数值 |
| DH | 48 通道选择矩阵、次数、间隔、等待时间 | 报告选择器及 23 路状态/遥测表；失败时遥测显示不可用 |
| 舵控 | 波形、频率、幅值、偏置、相位、扫频上限、4 路使能 | 10 组指令/FK1-FK4 折线图和自检状态表 |
| 定时器 | 基线/C2H0 负载选择 | 8 个互斥抖动桶柱状图、总样本、平均值和最大值 |

每页右侧保留“结果 / 原始字段”两个视图。原始字段表从 `ProtocolCatalog` 获取中文名、字段名和类型，便于协议诊断。

## 实施步骤

1. 先新增页面测试，锁定 12 个页面全部存在、参数能正确序列化、响应只更新对应页面，以及 DH、舵控和定时器的特殊展示行为。

2. 在 `ui_theme.py` 定义中性灰白工作台主题，沿用青绿色主操作色和现有日志语义色。控件圆角不超过 6px，不使用渐变、装饰动画或新增图标依赖；按钮继续使用 `QStyle` 标准图标。

3. 在 `test_page_widgets.py` 实现以下稳定接口：

```python
class BaseHardwareTestPage(QWidget):
    run_requested = pyqtSignal(str, object)

    def collect_parameters(self) -> Dict[str, object]: ...
    def reset_for_run(self) -> None: ...
    def render_response(self, decoded: DecodedMessage) -> None: ...
    def set_test_status(self, status: str, detail: str) -> None: ...
    def set_actions_enabled(self, enabled: bool) -> None: ...
```

同时实现 `MetricGrid`、`BitGrid`、`RawResponseTable` 和 U32 十六进制输入控件。参数错误在页内显示并聚焦对应字段。

4. 在 `hardware_test_pages.py` 实现 12 个明确命名的页面类和 `create_test_page(spec, catalog)` 工厂。舵控和定时器使用现有 matplotlib 3.3.4 的 `FigureCanvasQTAgg`，不引入 `pyplot` 或新依赖。

5. 重构 `MainWindow` 为单个 `QTabWidget`，标签位置设为 `West`：

```text
连接与日志
串口回显
系统状态
内存
SPI Flash
总线
DI
DO
电源
电气健康
AD
DH
舵控
定时器
```

删除 `test_tree`、动态 `parameter_form` 和全局 `response_table`，建立 `pages_by_key` 和 `tab_index_by_key` 映射。

6. 窗口顶部保留一条紧凑状态栏：当前 Windows COM、连接状态、当前解析模式、连接/断开、执行全部和停止。详细串口配置及完整彩色日志放入“连接与日志”页。

7. 标签切换规则：

- 进入“串口回显”页时启用回显解析。
- 进入任一硬件页时启用产品协议会话。
- 进入“连接与日志”页不改变当前解析模式。
- 请求在途时禁用会改变解析模式的标签，但允许查看连接与日志及其他同模式硬件页。
- 切换标签不得取消正在执行的测试或清空结果。

8. 每个页面的执行按钮调用 `session.run_test(key, page.collect_parameters())`。执行全部先收集所有页面当前参数，再调用 `session.run_all(overrides)`；任一页面参数无效时定位该页且不发送任何请求。

9. 按 `key` 将 `response_received` 路由到对应页面：

- 普通测试替换该页最近结果。
- DH 保存多帧报告并允许选择查看。
- HELM_START/STOP ACK 不覆盖反馈曲线。
- TIMER_STOP ACK 不覆盖 START 的桶统计。
- 非零 `status/err_code` 更新状态和原始字段，但不把默认零值解释为有效测量。

10. 更新文档中的顶部模式切换、测试树和右侧日志描述；不新增重复 UI 文档。
