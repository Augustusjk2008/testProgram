# 实际测试项（兼容索引）

本路径为兼容旧链接保留，不再逐项复制需求表、阈值、协议字段、宿主页面或台架点位。旧版内容把未落地技术条件与当前软件行为混在同一张表中，容易被误读为已经实现的判据。

当前事实按职责查阅：

- 产品端命令、执行顺序、字段语义和硬件行为：当前 [`dut/src/`](../../../src/) 与[产品协议设计](codedesign.md)；
- 字段偏移和线序：本目录的协议 CSV；
- 宿主配置、运行模式、算法判定和事务边界：[设备通信协议契约](../../../../docs/design/contracts/device-communication-protocol.md)与当前 [`configs/`](../../../../configs/)；
- PXI 夹具端点、量程和安全态：[HAL 接口协议](../../../../docs/design/contracts/hal-interface-protocol.md)；
- 自动化清单、执行命令和证据等级：[测试规范](../../../../docs/design/testing/testing-specification.md)。

技术条件若没有进入当前源码、配置或现行契约，就不是当前软件的验收判据。需要新增或改变判据时，应先完成需求评审，再同步配置、实现、契约和回归测试。
